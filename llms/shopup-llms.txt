# ShopUp

> ShopUp is a Bangladesh technology company connecting mills and manufacturers to a network of small neighbourhood shops. It operates Mokam (B2B commerce) and REDX (last-mile logistics / courier). REDX exposes a public merchant API for creating and tracking parcels.

## APIs
- [REDX Open API](https://redx.com.bd/developer-api/): Merchant courier API — create/track parcels, manage pickup stores. Base https://openapi.redx.com.bd/v1.0.0-beta, sandbox https://sandbox.redx.com.bd/v1.0.0-beta.

## Specs
- [OpenAPI](openapi/shopup-redx-openapi.yml): REDX Open API (7 operations, apiKey auth via API-ACCESS-TOKEN header)
